 AI Pipeline

          
1
NLP Parse — Gemini extracts entities, flows, edge cases

          
2
Gherkin — Feature file with Background, Scenario Outline, Examples

          
3
Step Defs — Python/Java with Selenium locators & waits

          
4
Synthetic Data — Test cards, PNRs, promos, passengers
